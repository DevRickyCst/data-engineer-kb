# Data Engineer Knowledge Base

A focused, opinionated knowledge base covering the topics that actually come up in real data-engineering work and interviews.

## What's inside

- **Data Modeling** — SCDs, normalization, schema design
- **Data Pipeline** — orchestration (Airflow), streaming (Kafka)
- **Interview Prep** — questions answered at Junior / Mid / Senior level, with common pitfalls

## How to use this site

1. Browse topics from the **sidebar**.
2. Use the **search** (top-right) to jump to a concept.
3. Pages are written in Markdown/MDX — contribute by editing files in `/docs`.

## Conventions used

- **SQL** snippets use ANSI SQL unless noted.
- **Python** snippets target 3.10+.
- **Diagrams** use [Mermaid](https://mermaid.js.org/) and render natively.

> Found something wrong or missing? Open the corresponding `.md` file under `docs/` and edit it directly.
